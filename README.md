## Project Name
Water Level Indicator

## Project Scope
This project detects water levels and indicates low, medium and high levels using LEDs and buzzer using Arduino UNO.

## Components Used
- Arduino UNO
- Potentiometer
- LEDs
- Resistors
- Piezo Buzzer
- Breadboard

## Software Used
- Tinkercad
- Arduino IDE

## Features
- Low water indication
- Medium water indication
- High water indication
- Buzzer alert
